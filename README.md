# Comp1004Project - Password Improver

In this project you will find a basic password improver SPA, this program is written to help improve peoples passwords by simily entering there password
in and it will output some basic but helpful tips and ideas on how to improve the password they have entered.

To install and run this program please install all three files (HTML, CSS and JavaScript) and run the HTML file.

This project works by inputting a string from the text box in the HTML file and clicking the "submit" button, this will then be sent over to the JavaScript file
due to the event listener and will be stored in a var, from here the stored var will be run through a variety of if statements that will check for certain
perameters and will output to the HTML file based on what has been inputted, furthermore the if statements will add to the grade system made and calculate a 
grade based on how strong the password is.
